ROBBERT & MELLANIE — WEBSITE V2
===============================

Deze map is klaar om als statische website op GitHub Pages te plaatsen.

Belangrijkste V2-aanpassingen:
- Nieuwe foto van de buitenkant van de Arendshoeve/showkas.
- Nieuwe verticale Botanical Chic sfeerfoto.
- Nieuwe foto van Robbert & Mellanie.
- Hartjesfoto bij de cadeauwens.
- Gouden R&M-monogram in header, hero, footer en bedankpagina.
- Correcte links voor B&B Westeinder en B&B Hogervorst.
- Aangepaste teksten voor cadeauwens, ontbijt, overnachten en kinderen.
- RSVP gebruikt Web3Forms en stuurt na succesvolle verzending via JavaScript naar bedankt.html.

GITHUB PAGES
1. Upload index.html, bedank.html, styles.css, script.js en de volledige assets-map naar de root van je repository.
2. Zet GitHub Pages aan via Settings > Pages.
3. Test de RSVP vanaf de gepubliceerde GitHub Pages-URL.

WEB3FORMS
De Web3Forms access key staat al in index.html.
De site verstuurt het formulier via JavaScript naar Web3Forms. Zodra Web3Forms een succesvolle response teruggeeft, gaat de browser naar de lokale bedankt.html. Daardoor verschijnt niet langer de algemene Web3Forms-succespagina.

Test na upload minimaal:
- een RSVP met 'Hele dag' + diner/menu;
- een RSVP met losse onderdelen;
- een afmelding ('Helaas niet');
- de bedankpagina op mobiel en desktop.
